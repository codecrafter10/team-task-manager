# Leak Blocker – A Paper Leakage Detection System

## Overview

Leak Blocker is a secure and intelligent examination paper management system designed to prevent question paper leakage during the examination process. The system uses modern technologies such as blockchain, encryption, authentication, monitoring, and access control to ensure the confidentiality and integrity of examination papers.

The project aims to provide a transparent, tamper-proof, and highly secure environment for educational institutions, universities, and examination authorities.

---

# Problem Statement

Question paper leakage has become one of the major issues in educational systems. Traditional methods of storing and transferring examination papers are vulnerable to:

* Unauthorized access
* Data tampering
* Insider threats
* Paper distribution leaks
* Lack of transparency
* Weak tracking systems

These issues can compromise the fairness of examinations and damage the credibility of institutions.

---

# Solution

Leak Blocker provides a secure digital platform where examination papers are:

* Encrypted before storage
* Securely uploaded by authorized admins
* Monitored through blockchain-based tracking
* Accessible only to verified users
* Protected using authentication and role-based access
* Logged for every activity and transaction

The system ensures that every action performed on a question paper is recorded securely and cannot be modified.

# System Architecture

1. Admin uploads question paper.
2. Paper is encrypted before storage.
3. Blockchain transaction is generated.
4. Secure hash is stored in blockchain ledger.
5. Authorized users access papers through authentication.
6. All activities are monitored and logged.
7. Suspicious activities trigger alerts.

---

# Workflow

## Step 1 – Admin Authentication

The administrator securely logs into the system using authorized credentials.

## Step 2 – Question Paper Upload

The admin uploads the examination paper into the system.

## Step 3 – Encryption Process

The uploaded paper is encrypted to protect sensitive information.

## Step 4 – Blockchain Verification

A blockchain transaction is generated to create a tamper-proof record.

## Step 5 – Secure Storage

The encrypted paper is securely stored in the database/cloud.

## Step 6 – Controlled Access

Only authorized users can access the paper at a predefined time.

## Step 7 – Activity Monitoring

All actions are monitored and stored in logs.

## Step 8 – Security Alerts

The system sends alerts if suspicious activity is detected.
